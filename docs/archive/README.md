# docs/archive

Dated analyses kept for the reasoning in them, not as current references. Read `docs/ARCHITECTURE.md` and `docs/agents.md` first.

- `DEVELOPMENT_MAP.md`: the first repository analysis (2026-08-10), written before the code could be read; its map of the documents and its milestone plan are historical. `docs/DECISIONS.md` cites it by name.
- `code_agent_flow.md`: the Code Agent as the code did it on 2026-10-12, with `file:line` anchors that were true at that commit; D-103 and later changed the code, so line numbers are stale.
- Why archived: both are accurate descriptions of a past state, valuable as rationale, misleading as a description of today's code.
- The commit ids and branch names they cite belong to the original git history; a repository delivered without that history cannot resolve them.
- Files they name that are not in the repository (session logs, planning documents) stay with the author.
